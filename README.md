# Kolkata House Price Predictor

## How This Project Was Built & Deployed

1. Downloaded a house price prediction Jupyter notebook from Kaggle.
2. Uploaded the notebook to Claude and gave the prompt to create an `app.py`
   file based on the uploaded file, customized for INR instead of Dollar,
   with the location set to Kolkata, India.
3. Claude produced an `app.py` file, a `requirements.txt` file, and a
   `train_model.py` file.
4. Once the files were created, downloaded those files into a folder on a
   laptop.
5. Logged into GitHub and created a new repository named
   `house-rate-predictor`.
6. Uploaded all the files downloaded from Claude into the repository.
7. Logged into the Streamlit application using "Continue with GitHub".
8. In Streamlit, gave the name and description of the application, selected
   the application access as "Public", and clicked on "Create New" at the
   top left corner.
9. The application asked for details on the screen, like repository path,
   `.py` file name, and web application name.
10. After filling in all the details, clicked on "Deploy" at the bottom.
11. Streamlit created the web application, and the URL was shared in the
    group.
